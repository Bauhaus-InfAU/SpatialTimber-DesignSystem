SpatialTimber · Component Library

The parts every screen is built from.

A reference for the shared component layer behind the Aufstockung Assistent and its sibling tools. Warm paper, one clay accent, hairline geometry, tabular numerals. Every class is prefixed st- and built on the design tokens — lift them straight into a real codebase.

625 mm grid Inter + JetBrains Mono AA · keyboard · reduced-motion
00 — Foundations

Tokens before parts.

03 — Surfaces

Hairlines, not drop shadows.

Depth comes from the fill step — paper to card to oat — and a single hairline rule. One soft diffuse shadow is reserved for cards and floating overlays. Large radii throughout.

Card · panel · inset

Raised surface on card fill with hairline and one soft shadow. The default container.

Panel

Flat paper surface, hairline only — for quieter groupings inside a card.

Oat inset — a quiet block for a nested value or note.

06 — Feedback

Restrained, never alarming.

Status reads from a single keyed border and an ink-line icon — no coloured fills shouting for attention. Info leans sky, success olive, warning clay; the rest stays neutral.

Inline alert / banner

Survey snapped to grid

The imported footprint was aligned to the nearest 625 mm module. Review the north-east corner.

Layout meets the mix target

All four apartment types are within tolerance. Ready to export to the structural model.

Utilization below 0.80

Two wall-beams are under-loaded. Consider removing a support point or reducing section depth.

Closing note
