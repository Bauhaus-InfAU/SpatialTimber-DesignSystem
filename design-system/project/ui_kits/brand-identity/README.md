# Brand identity — UI kit

`index.html` is the **brand-identity reference page**: it renders the full SpatialTimber identity
on one page — the stacked-storeys logomark and its variants, the `SpatialTimber` wordmark, the
sub-project lockups (shared mark + module name + glyph), the module glyphs, the colour system, and
the type stacks (Inter + JetBrains Mono).

Open it in a browser to *see* the brand. It is self-contained (inline CSS/SVG — no external
assets). To regenerate the marks/glyphs it shows, use the generator in
[`../../assets/spatialtimber-assets.mjs`](../../assets/spatialtimber-assets.mjs); the canonical
tokens are in [`../../colors_and_type.css`](../../colors_and_type.css). The narrative rules behind
the page live in [`../../README.md`](../../README.md).
