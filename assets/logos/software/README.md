workflow — for use in slides, diagrams, and tool-chain / interoperability figures. These are
**not** funder logos (those live one level up in [`../`](../)).

Prefer the **SVG** versions wherever possible (crisp at any scale). Extracted 2026-06-07.

- **Rhino** and **Grasshopper** had no SVG on Wikimedia. Rhino is shipped as the official
  transparent PNGs from McNeel; Grasshopper as a vector SVG (white-field) plus the official
  64 px green-field site icon — pick whichever field suits the layout.
- **Revit** is the full wordmark+icon lockup; **Archicad** is just the rounded-square app icon
  (`#00A0D1`). Mixing wordmarks and icons here is intentional — use the form that fits the figure.
